
The Horse Logic query app provides a suite of tools for analyzing and querying horse experiment log files.

### Getting Started

To begin using the app, follow these simple steps:

1. **Login**: Use the sidebar to log in with your credentials. Authentication is required to access the app's features.

2. **Upload Log Files**: Navigate to the 'Upload' section to add new log files for analysis. Accepted formats are `.log`.

3. **View Experiments**: The 'Experiments' tab allows you to view a list of all experiments and associated details.

4. **Query Data**: Use the 'Query' tab to execute custom SQL queries on the dataset. Results can be viewed directly within the app.

5. **Statistics**: Access the 'Statistics' tab for a visual representation of the data, including charts and graphs.

6. **Download Data**: Extract and download data reports from the 'Download' section in various formats like CSV or Excel.

### Features

- **Secure Login**: Protects sensitive data and ensures that only authorised users can access the app.

- **Data Upload**: Easily upload and store log files to be included in the analysis.

- **Data Visualisation**: Interactive charts and graphs provide insights into the experimental data.

- **Custom Queries**: Run custom SQL queries for advanced data analysis.

- **Error Handling**: The app includes error handling to ensure stability and provide user feedback.
